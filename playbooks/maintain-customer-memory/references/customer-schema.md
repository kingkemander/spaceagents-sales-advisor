# 客户状态结构

`customer.json` 顶层字段：

- `schema_version`
- `customer_id`
- `name`
- `aliases`
- `owner`
- `source_channel`: 抖音、转介绍、活动、官网、自然到访等首次来源
- `company_name`
- `job_title`
- `industry`
- `contacts`
- `status`: `prospect`、`active`、`won`、`lost`、`paused`、`dormant`
- `stage`
- `intent_level`: `high`、`medium`、`low`、`unknown`
- `needs`
- `budget`
- `timeline`
- `decision_chain`
- `objections`
- `competitors`
- `last_contact_at`
- `next_followup_at`
- `latest_update`
- `followup_reason`
- `next_action`
- `reply_suggestion`
- `risks`
- `won_details`
- `lost_details`
- `unconfirmed`
- `evidence`
- `created_at`
- `updated_at`

数组字段写短句。不得保存密码、证件号码、银行账号或与销售工作无关的敏感信息。
