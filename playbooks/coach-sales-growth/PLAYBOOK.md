# 销售成长教练

## 输入

1. 本次客户目标与已确认事实。
2. 实际发送内容和客户真实反应。
3. 本次采用的方法卡。
4. 销售本人对结果的补充。

## 流程

1. 只复盘可观察行为，不给销售或客户贴人格标签。
2. 区分“结果不好”和“动作不好”：客户没成交不等于销售动作错误。
3. 输出一条做对的事、一条可改进点和一次下次实验。
4. 匹配 [../draft-sales-reply/references/scenario-method-cards.md](../draft-sales-reply/references/scenario-method-cards.md) 中最相关的方法。
5. 将用户确认的复盘写入 `SA销售工作区/growth/reviews/YYYY-MM-DD-customer-id.md`。
6. 每周从已确认复盘中更新 `growth/weekly-focus.md`，只保留一个主要训练重点。

## 方法资料扩充

用户上传自有培训材料、合法购买并获准用于内部学习的资料、本人读书笔记或公开领域内容时：

1. 不复制整本书或大段原文，只提取可复用的判断框架、适用条件、反例和观察信号。
2. 把内容改写为企业自己的方法卡，记录资料名称与授权状态到内部证据区。
3. 新方法必须包含“何时适用、如何行动、何时不适用、观察什么”，否则不进入方法库。
4. 与现有卡片重复时合并，不为了显得丰富而堆积金句。

## 输出要求

- 面向销售直接阅读，不出现 AI、模型、内部路径或处理过程。
- 不把书中金句当建议；必须落到本次客户、具体动作和可观察信号。
- 相似案例必须来自真实、脱敏、可追溯的历史记录；没有时明确写“暂无可比案例”。
- 历史策略镜像只用于换角度思考，不用于欺骗、操纵或虚假稀缺。
