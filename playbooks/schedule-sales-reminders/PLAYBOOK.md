# 销售提醒与排期

## 识别提醒类型

根据用户原话选择最小任务类型：

1. **一次性行动提醒**：在指定时间提醒完成一项销售动作。
2. **到点完成确认**：到点给出任务内容并询问“完成了吗”。
3. **每日销售行动简报**：每天或工作日按最新客户状态刷新看板并生成文字清单；看板只更新，不自动打开。
4. **每周销售复盘**：汇总完成、延期、无反馈和下周关键节点。
5. **半年客户推进计划**：生成未来六个月的阶段安排，只为关键节点创建自动提醒。

提醒内容格式和可直接放入自动任务的提示词见 [references/automation-prompts.md](references/automation-prompts.md)。

## 创建规则

1. 用户明确说“提醒我”“每天告诉我”“到时候问我”即视为创建授权，不再重复确认。
2. 从用户原话提取时间、时区、重复规则、客户和动作。使用当前本地时区；创建前把相对时间解析为明确日期时间。
3. 仅在时间确实无法判断、指定时间已经过去且无法确定用户指今天还是明天、或缺少必要客户/事项时，询问一个最小问题。
4. 查找当前环境的自动任务能力并直接创建或更新；不要用网页模拟点击。创建成功后返回任务名称、首次触发时间和重复规则。
5. 创建前检查相同标题、客户、时间和重复规则的任务；已有相同任务时更新，不重复创建。
6. 如果当前环境没有自动任务能力，明确说明没有创建成功，并给出可复制的任务提示词；不得假装已设置。

## 运行时读取最新状态

自动任务触发时重新读取 `SA销售工作区/indexes/customer-index.json` 和相关 `customers/*/customer.json`，不得把创建任务当天的客户状态永久冻结在提示词里。

需要具体回复时读取 `<运行时根目录>/playbooks/draft-sales-reply/PLAYBOOK.md`，结合客户最新事实和 `config/sales-soul.md` 生成一条销售本人可以直接复制的消息。

默认直接在 SpaceAgents 当前任务中发送文字，不要求用户打开 HTML 作战台。只有用户明确要求“打开看板”或“生成看板”时才生成页面。

## 每日文字行动清单

每次最多列出 5 位真正需要行动的客户，按时间顺序输出：

```text
【今日销售行动｜YYYY-MM-DD】

09:30｜客户名
要做：本次唯一动作
原因：为什么必须现在做
建议发送：一条可直接复制的消息

15:00｜客户名
要做：本次唯一动作
原因：为什么必须现在做
建议发送：一条可直接复制的消息

今天最重要的一件事：……
```

没有事实依据时不强行安排联系；改为提示补资料、内部准备或暂缓。绝不自动向客户发送消息。

## 到点完成确认

提醒触发时不要只说“您有一个提醒”。必须重述行动和对象：

```text
【15:00 行动确认】
今天安排：把 12 号楼平面图和付款方案发给吴总。

建议发送：……

这件事完成了吗？
你可以回复：已完成 / 延后到具体时间 / 帮我改一下话术。
```

用户回复“已完成”时，只有明确关联客户且用户同意写入时，才把完成结果更新进客户时间线；否则只结束或更新该提醒。

无论是否写入客户时间线，都要把已完成事项记录到本地任务事件流水，供每天 18:00 私人知识库同步使用：

```bash
python3 "<运行时根目录>/sa_sales_advisor/cli.py" activity add \
  --root "<当前项目>/SA销售工作区" \
  --event-type "completed" \
  --title "<已完成事项>" \
  --customer-id "<可选客户 ID>" \
  --customer-name "<可选客户名>" \
  --details "<完成结果>"
```

## 半年推进计划

1. 从已确认的客户周期、承诺、交付、预算和决策节点生成未来六个月安排。
2. 保存到 `SA销售工作区/plans/sales-plan-<YYYY-MM-DD>.md`。
3. 按“本周、未来 30 天、第 2–3 个月、第 4–6 个月”组织；每个阶段包含目标、关键客户、准备材料、触发条件和退出条件。
4. 不虚构客户日期。没有明确日期时写成条件触发，例如“客户确认预算后 2 个工作日内提交方案”。
5. 默认只创建一个每日简报和必要的一次性关键节点提醒；不要为半年中的每一天创建任务。只有用户明确要求时才增加每周或每月复盘。

## 固定边界

- 自动提醒销售本人，不自动联系客户。
- 不自动发送微信、短信、邮件或企业微信消息。
- 不把未经确认的价格、库存、交付和优惠写进建议消息。
- 不用“系统分析”“AI判断”“读取文件”等内部措辞；提醒只呈现清晰的销售行动。
