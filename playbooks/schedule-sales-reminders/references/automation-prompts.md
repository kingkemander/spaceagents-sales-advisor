# 自动任务提示词

## 目录

1. 一次性行动确认
2. 每日销售行动简报
3. 每周销售复盘
4. 关键客户节点提醒
5. 半年计划滚动检查

以下提示词中的变量必须在创建任务时替换为当前工作区、客户和时间。任务运行时必须重新读取最新客户状态。

## 1. 一次性行动确认

```text
这是一次销售行动提醒。现在是计划时间 {{scheduled_at}}。

读取 {{workspace}}/SA销售工作区 中与 {{customer_name}} 相关的最新客户档案。提醒销售完成：{{action}}。

直接输出文字，不生成或打开看板：
【{{time_label}} 行动确认】
今天安排：{{action}}。
客户：{{customer_name}}。
为什么现在做：结合最新客户状态，用一句话说明。
建议发送：根据已确认事实和销售个人口吻，给出一条可直接复制的消息；如果本事项不需要联系客户，则改为“完成标准”。
最后询问：这件事完成了吗？可以回复“已完成 / 延后到具体时间 / 帮我改一下话术”。

不要自动联系客户，不虚构价格、库存、交付或承诺。
```

## 2. 每日销售行动简报

```text
运行 SA 销售军师的每日文字行动流程。读取 {{workspace}}/SA销售工作区 中最新客户索引、客户状态、承诺、跟进日期和销售个人表达资料。

先刷新 SA销售工作区/dashboard/index.html，但不要自动打开页面。然后直接在当前任务发送文字，只列真正需要今天行动的客户，最多 5 位，按建议执行时间排序。每位客户必须包含：
1. 时间与客户名；
2. 今天唯一要做的动作；
3. 为什么今天做；
4. 一条符合销售本人表达习惯、可以直接复制但需要人工发送的消息；
5. 如不该联系客户，改为内部准备、补资料或暂缓原因。

结尾给出“今天最重要的一件事”。不要输出文件路径、客户 ID、模型、AI、OCR、置信度或处理过程。不要自动联系客户。
```

## 3. 每周销售复盘

```text
读取 {{workspace}}/SA销售工作区 中最近 7 天的客户时间线和提醒执行结果，生成本周销售复盘文字：
- 已完成的重要动作；
- 延期或没有反馈的客户；
- 下周最重要的 3 个节点；
- 一项值得调整的沟通方式；
- 一位不应继续频繁打扰的客户。

只引用已有事实，不生成看板，不自动联系客户。
```

## 4. 关键客户节点提醒

```text
检查 {{workspace}}/SA销售工作区 中 {{customer_name}} 的最新状态。原计划节点是 {{milestone}}，计划时间为 {{scheduled_at}}。

如果节点仍有效，直接提醒销售下一步、准备材料和建议消息，并询问是否完成。如果客户状态已经变化，明确说明原计划已不适用，并给出一个最小调整建议。不要沿用过期话术，不自动联系客户。
```

## 5. 半年计划滚动检查

```text
读取 {{workspace}}/SA销售工作区/plans 中最新半年销售计划，以及所有活跃客户的最新状态。检查未来 30 天：
- 已到期和即将到期的关键节点；
- 需要提前准备的资料；
- 决策链、预算或项目周期仍不清楚的客户；
- 应新增、调整或取消的提醒。

直接发送简洁文字建议。只有在用户已授权的排期范围内更新自动任务；不批量创建无明确价值的每日任务，不自动联系客户。
```
